## 一路电路验证后复制八路

按压电阻下降时采用以下分压方向，B先用万用表核实实物行为、静止/轻按/重按电压与范围：

```text
3.3V ─ 压力片 ─┬─ MCP3208 CHi
                │
               2kΩ
                │
               GND
```

MCP3208按官方DIP图确认缺口、VDD/VREF/AGND/DGND/CS/CLK/DIN/DOUT。3.3V供电与参考、100nF靠近VDD；先已知分压电压验证读数，再接压力片。

MAX98357A按实际模块说明确认供电、使能、声道、增益与BCLK/LRCLK/DIN；信号侧共地，FPGA选已确认3.3V GPIO。喇叭接两功率输出端，任一端不是GND。柔性尾部按厂家说明连接，保护受力。

## 上电前与接线表

- [ ] A/B核对板卡版本、Bank电压、GPIO复用，不混接1.5V与3.3V。
- [ ] B核对裸ADC方向/电源/地/去耦，断电查短接，再测供电。
- [ ] 一片压力电压变化正确，不超ADC范围。
- [ ] MOSI→DIN、DOUT→MISO，通道与键标号。
- [ ] A核对功放电源/使能/输入与喇叭，低幅测试。
- [ ] 线缆与柔性尾部固定，临时改线记录并恢复。
