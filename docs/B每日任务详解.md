# B 每日任务详解：压力电路、MCP3208 与八键输入

更新：2026-10-10。按数电/Verilog基础编写。配合[总计划](三人分工与交付计划.md)、[接口](接口约定.md)、[器件接线准备](器件与接线准备.md)、[验收记录](交接与验收记录.md)。只有一块板，不等全部结构做好才开始采集。

## 你到底把什么交给队长

压力片是随按压改变电阻的器件，不直接输出数字，也不是只输出0/1的按钮。分压变成电压，MCP3208把电压变为0…4095的12位数；你的逻辑再把它变为每键gate和16位gain。

```text
CH0…7原始电压 → ADC原始值 → 逐键校准/识别/平滑
→ gate[7:0]、key_gain[127:0]、controls_valid
```

原始值、按住状态、音量增益是三种东西。把电气和校准处理放在B模块中，不让队长合成核心判断哪个ADC数字算按下。

SPI选择模式0起步：SCLK空闲低，命令在采样上升沿前稳定，下降沿推进下一位；MISO按手册的输出时序在接收沿采集。参考[官方MCP3208手册](https://ww1.microchip.com/downloads/en/DeviceDoc/21298E.pdf)，不要从MCP3008代码只改文件名就用。

以下DIP-16连接用于核对，不替代实物朝向检查；从缺口/圆点对应1脚、顶视图确认：

| DIP脚 | 功能 | 本项目连接方向 |
|---|---|---|
| 1…8 | CH0…7 | 八片分压中点 |
| 9/14 | DGND/AGND | 按手册接地，共地 |
| 10 | CS/SHDN | FPGA输出，低有效 |
| 11 | DIN | FPGA MOSI输出到ADC |
| 12 | DOUT | ADC输出到FPGA MISO |
| 13 | CLK | FPGA SCLK输出 |
| 15/16 | VREF/VDD | 目标3.3V参考/供电，核对去耦 |

MCP3208是裸芯片，不能当接了VCC就完整可用的模块。不要把扬声器功率输出当公共地。

## 10/10：整理实物、搭一路分压

**学什么：** 面包板电源轨/同排连接、分压、共地、万用表电压和电阻测量的区别。

**具体做：**
1. 把八片压力片标K1…K8、计划对应CH0…7；确认ADC型号、方向、2kΩ电阻、电容和线材。
2. 断电检查面包板哪些孔相连、长电源轨是否中间断开；不能只按红蓝标线猜。
3. 在断电的独立传感器上比较不按/轻按/较重按电阻，确认行为；通电电路不使用电阻档。
4. 与A核对可用3.3V电源和地，搭3.3V→压力片→中点→2kΩ→GND，只测一路电压。
5. 记录静止、轻按、较重按电压，按压应向上，范围0…参考电压；先不接未核对的数字GPIO。
6. 按实际板卡资料与A选CS/SCLK/MOSI/MISO候选脚，Bank电压和复用没确认前不下载驱动。

**验收/交接：** 供电正确、分压变化可重复、无短接，接线照片/电压记录交A；给队长解释“按住状态”和“连续力度”来源。

## 10/11：画 ADC 事务并写 SPI 初版

**学什么：** CS控制一笔事务，命令选择通道，时钟同时发送/接收，状态机结束产生valid。

**具体做：**
1. 从官方时序画Start、单端位、三位通道、空位、B11…B0，数清结果所在位置。
2. 起步使用24个SCLK的字节对齐事务：前导零、Start、单端选择、通道命令与结果按手册对应，不猜“最后12位”位置。
3. 50MHz下每50主时钟翻转SCLK，完整周期100主时钟=500kHz；使用主时钟使能生成输出，不另开不必要时钟域。
4. 写空闲、启动、移位、结束、valid状态，CS低前后有明确稳定时间；通道输入在启动时锁定。
5. 写仿真ADC模型：解析真实命令后按该通道返回给定12位数，不直接读取DUT内部channel作弊。

**验收/交接：** 一笔事务不重发/截断，SCLK/CS空闲正确、valid一次；模型能收到单端CH0命令。交A逻辑端口和拟用引脚，尚未上板不写通过。

## 10/12：指定数值仿真与已知电压验证

**具体做：**
1. 用0、1、12'hABC、4095和交替值测试接收，检查12位位序与前导空位，结果准确匹配。
2. 用模型给不同通道不同值，确认选择命令真正变化；连续事务之间CS恢复高，起步保留2µs间隔。
3. 按DIP图搭ADC电源/参考/两地/100nF；与A核对FPGA信号脚和CST后上板。
4. 先把CH0接GND，随后用两只2kΩ形成约半参考电压，万用表量实际中点；预期原始值约2048，按实测电压/VREF核对。
5. 给调试top增加8位显示：使用6个LED显示原始值的高6位/低6位、1个LED标页，约每秒换页；先锁定一次原始值再换页，避免拼成不同采样。剩余LED作valid/运行指示；具体LED脚由A核对。以后可用Gowin Analyzer观察，不能为读数额外引入未计划MCU。

**验收/交接：** 模型全部测试数准确；真实GND接近0、半参考接近半量程且方向正确；保存读数/电压/误差来源。若只有粗略LED观察，写功能初验，后续补完整数值记录。

## 10/13：第一片变为 gate 和力度

**学什么：** 原始ADC码不是直接的音量；阈值、映射、16位打包。

**具体做：**
1. CH0接第一片分压，保存静止、轻按、较重按读数并与电压对应。
2. 选择能分开静止噪声和轻按的初始阈值，先做一键状态和增益映射。
3. 增益0…65535限幅，按住有可用最小值；不做浮点实时计算，使用整数比例/校准常量。
4. 从第一天输出gate[7:0]、key_gain[127:0]；CH0放最低16位，其他七路为零，按约定给controls_valid。
5. 给队长假控制和真实控制各一组示例，确认按下时增益不是零。

**验收/交接：** 同一键持续按压力度能变，不只给pressed脉冲；gate是按住状态。交CH0数据范围、打包例子和控制更新周期。

## 10/14：一键真实闭环与校准

**具体做：** 联调时保持一个键，轻重改变压力，再松开。与A先看ADC→gate/gain，输入正确后交队长看音频，输入错误由B修。记录静止噪声范围、按下与松开读数，以及可能的机械预压。

**验收/交接：** 静止不误响、按下可重复、力度可持续变化；交A接线/输入证据，队长理解增益范围。ADSR尚未加入时松开立即停止正常，不冒称包络通过。

## 10/15：扫描八路与整组交接

**学什么：** 一次读取一个通道；八路同时控制不代表ADC物理同时采样；完整帧需缓存。

**具体做：**
1. 依次CH0…7读入raw[0…7]，一轮结束才更新控制输出与valid，不能每读一路就更新半组。
2. 500kHz下24时钟约48µs，八笔约384µs，再加CS间隔和处理仍应小于1ms；按每50,000个主时钟启动一轮，实测/仿真记录而非只写目标。
3. 本轮未结束就到新轮时记录超时，不重叠覆盖；正常无超时。
4. 模型每路返回不同值，如100/200/…/800，在扫到CH4时检查对外帧仍是上一完整组。
5. 验证CH7结束后一次valid，下一组和上一组数据不串。

**验收/交接：** 完整八通道原始帧，1ms周期和打包顺序正确；交队长完整帧与valid时序，A准备总工程。

## 10/16：前四键滞回、稳定判定和平滑

**具体做：**
1. 分别记录前四片静止/轻按/重按，Ton高于Toff，保持区间不改变状态。
2. 连续两轮满足按下才gate=1，连续两轮满足松开才gate=0；中间不满足则按规则清稳定计数，避免偶发噪声累积。
3. 平滑旧值+(目标−旧值)/4使用有符号差值与额外精度；目标比旧值小仍正确下降。
4. 模型注入阈值附近交替噪声、单轮尖峰、长按、松开、力度阶跃；不能用几十ms大滤波把延迟拖慢。
5. 松开帧gain可归零，与队长测试同帧gate下降，核心必须冻结此前力度。

**验收/交接：** 前四键不抖，力度上下都能变化；后四路gate/gain保持零；交校准表、稳定/滤波时间和可复现数据。

## 10/17：四键接口与实物布局

**具体做：** 四路电路复制后逐片独立检查；交完整八键格式，每帧后四路零。用软垫/按压片使压力集中在有效区，传感器和尾线固定；不让一键传力到相邻键。面包板、电源线、通道线标号。

**验收/交接：** A可按表接，队长可按编号发音；四键同按不丢某键，原始值/状态对应正确。

## 10/18：四键实物验收

**具体做：** 按下四键保持、只放第二键、只变第三键压力、快速重复其中一键。把预期gate位和实测帧交A，帮助区分输入串扰和核心声部串扰。调整机械预压后重新校准。

**验收/交接：** 真实四键独立触发/保持/力度；线缆和布局记录，未通过列负责人。

## 10/19：后四片校准

**具体做：** 同样流程搭CH4…7，每路实测，不直接复制CH0阈值。给不同传感器不同按压，确认CH5不会误更新CH4。填写完整八键校准表；装配方式改变后再看静止值。

**验收/交接：** 八路原始采集正确、通道无错位；交队长后四路范围，A接八键。

## 10/20：八键结构与完整帧

**具体做：** 八键布局固定，传压与回弹/松开可靠，尾线受力保护；电源、地、SPI线分组标号。扫描后统一输出八键状态/力度。不要让结构遮住待测电压点，给A测量留接点。

**验收/交接：** 八键同按/松开可识别，无某路长期贴边或浮空；交接线版号、照片、校准数据。

## 10/21：八键独立性联合验收

**具体做：** 所有键同按，再从K1到K8逐路放；保持其他键压力，轻重改变一路。查看相邻原始值变化，区分结构传力、供电变化和软件串通道。修复后重验对应场景。

**验收/交接：** gate与独立增益正确；三人八键节点记录通过项和失败项，不只听和弦。

## 10/22：三个功能键同步、消抖、事件

**学什么：** 外部按键异步；同步减少亚稳态传播，消抖与事件是不同层。

**具体做：** 核对三个普通KEY方向/电压，经同步寄存器后稳定判定；仅稳定松开→按下产生单周期事件。机械功能键起步20ms消抖，作用于模式/音区，不把这个20ms套到压力琴键。长按不重复，松开再按可再触发，三位独立处理。

**验收/交接：** button_events[0/1/2]对应音色/音区/测试；B在50MHz输出，队长每拍接收，不用sample_ce截脉冲；交A按键操作与CST核对结果。

## 10/23：输入响应与测量准备

**具体做：** 仿真阶跃输入到gate/gain的周期数；记录真实扫描1ms、两轮稳定判定和平滑参数，区分触发通路与力度平滑。把每键电压阈值换算并标测点，与A确认输入触发起点；不要用平滑后内部gate冒充物理输入起点。

**验收/交接：** 交A阈值/测试通道/测点/参数，准备轻重不同触发。模型推算不是整机实测结果。

## 10/24：配合总延迟测量

**具体做：** 使用最终真实输入参数，稳定触发、记录不同通道/按压和扫描相位；不临时取消滤波只为测快。与A核对接法、电压和参考，不在功放测量时乱接地。输入太慢由B减少过度稳定/平滑后做误触发回归，再整机重测。

**验收/交接：** 输入条件与测量记录完整；如未借到仪器继续标未实测，不能用万用表代替。

## 10/25：重复性和线缆固定

**具体做：** 每键重复按放至少20次，记录漏触发/误触发；长按改变力度、松开后静止；三人30分钟连续演奏中观察掉线/供电/通道噪声。搬动与重新上电后复查结构预压和读数。

**验收/交接：** 线缆固定、接线表准确，校准随最终结构更新；冻结输入版本与记录。

## 10/26：写分压、ADC 和校准章节

**具体做：** 用实际电路图讲电阻→电压→12位数字→状态/增益；写3.3V参考、500kHz、1ms扫描、通道命令和缓存。校准表引用实测，不引用商品“精准压力”代替你们数据。

**验收/交接：** A可理解电路/协议，队长确认输入格式；章节参数与冻结RTL一致。

## 10/27：接线、照片与操作说明

**具体做：** 画/拍完整接线，写模块端子、FPGA脚、Bank、电压、有效方向与线标；图片能看清芯片朝向。操作说明包括上电、默认模式、压力演奏、三功能键和故障排查。

**验收/交接：** A照表可复接，不靠B口头记忆；不能把待核对GPIO填成示例脚冒充最终脚。

## 10/28：照表复核实物

**具体做：** 在断电状态逐线检查，ADC CH0…7与键编号、功放线和地一致；由A或队长照表复述/检查。复接后上电低幅验证，发现图与实物不一致更新版号。

**验收/交接：** 接线表可复现，现场搬动后也不靠猜线；A重建工程时使用同一接线/CST。

## 10/29：硬件技术结论复核

**具体做：** 查报告中的八键、独立力度、阈值、更新率、响应和结构是否都有记录。连续压力不是已标定牛顿值，未做速度检测不写“精确击键速度”。核对照片/校准与最终版本。

**验收/交接：** 报告真实、限制清楚，交A最终硬件章节。

## 10/30：演奏与结构视频

**具体做：** 按队长/A脚本操作，保持和弦改变一键压力，保持一键再选择其他键，演示松一路、模式、变调。镜头能看到动作，展示传感器、电路与固定，不靠后期音频掩盖问题。

**验收/交接：** 实物动作与声音对应，同版材料完整。

## 10/31：答辩练习

**具体做：** 回答为何需要ADC、SPI如何选通道、为何两阈值、如何防抖/平滑、八路为何整组交接、为什么各键校准、选音/力度如何分别控制。讲不清回看实测和自己代码。

**验收/交接：** 与A/队长互问，纠正文档；准备简单现场操作说明。

## 11/1：搬动与重上电演练

**具体做：** 模拟携带后摆放，断电查线、上电演奏八键和功能键；观察机械预压、线缆拉扯、接触不良。整理携带清单，固定面包板和模块。

**验收/交接：** 无临场焊线/改阈值也能演示；若结构改了，相关键重校准并通知A/队长。

## 11/2：提交前实物与说明检查

**具体做：** 核对八片、芯片、功放、喇叭、电源线和接线资料；检查报告图和实物同版，备用线材准备好。只修确定问题，不换整套结构造成未知预压。

**验收/交接：** 交A/B硬件材料签核，队长确认演奏与校准正常。

## 11/3：支持提交与必要补拍

**具体做：** A上传时核对硬件附件，照片清晰、接线/操作文件可打开。必要补拍与原视频版本相同；若硬件变动，通知队长/A并重验。

**验收/交接：** 提交材料真实对应实物，不漏校准和操作说明。

## 11/4：演示支持与缓冲

**具体做：** 断电检查松线，按既定顺序上电低幅测试；协助答辩或必要文件修正。截止日不把全部线路重新搭一遍。

**验收/交接：** 实物可靠、状态清楚、最终记录和备份齐全。

## 输入异常怎样定位

原始ADC不变：查电源/参考/CS/命令/通道/位序；原始变而gate不变：查阈值/连续计数；gain变大却音量变小：核对打包和符号，与队长定位；多键串扰：查传力/共地/供电/扫描缓存；松手音尾断：先确认输出按接口，再交队长检查冻结力度。每次仅改一处并记录复测。
