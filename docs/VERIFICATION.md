# 本轮Vibrato验证

当前结果见evidence/test_report.json。仿真、Gowin实现和实体上板独立记录。

## 音频数值与音高

163840个样本覆盖有符号极值、随机数据、缓存不足、平滑开关、旁路与持续正弦输入。
Python独立定点参考逐样本核对LFO插值、历史读取、音频插值及混合结果。
输出零交叉估算瞬时频率，拟合LFO速度和音高摆幅，并检查RMS与各周期峰值变化，区分音高调制和音量调制。
检查每份输出与输入严格相隔7拍、没有无请求输出、无未知数据，忙时额外输入记录overrun，复位/全零流不会泄漏旧RAM。
数值单元测试缩短输入样本间隔，波形分析按实际采样率48828.125Hz解释样本序列，不属于仪器实测。

## 蓝牙控制

外部UART波形测试VIBON/VIBOFF/VIBSTAT，TX引脚独立逐位解码，按完整回复字节核对。
覆盖默认关闭、无曲谱时控制、下载中开关且CRC保持、教学中开关不推进、STOP独立、非法命令、复位关闭。
保留原数量/CRC/256条曲谱、RAM地址标签、DONE与TEACH重启竞争、默认UART时间参数及按对即推进测试。

## 总工程

外部MCP3208模型响应实际SPI，真实压力帧驱动钢琴/吉他与教学。蓝牙命令实际控制音频模块。
检查两种音色全湿时的输出确实变化；关闭后逐样本与原合成PCM一致。
外部I2S逐字接收并对照处理后的PCM；频谱模块输入必须与同一处理后PCM相同，键高亮保持真实压力状态。
保留不同音区、按错/重复音/和弦、停止、复位、曲谱失效和音频欠载/丢样/ADC超时检查。
测试缩短UART、ADSR、LCD初始化和干湿过渡，正式顶层默认值未被替换。

## 本轮实际结果

全部12组检查PASS，40份正式Verilog文件通过顶层编译。
数值波形163840个样本逐样本一致，33025个完全旁路样本与原PCM逐位一致。
独立零交叉分析得到5Hz音高颤动，1000Hz中心音的相对变化幅度为1.02932%，输出/输入RMS比0.998691。以上为仿真波形分析，不是实物测试。
蓝牙新增命令30份回复逐字节核对通过。
完整顶层验证45帧ADC、2292560个时钟检查点、2598个非零I2S声道字、917084个LCD时钟边沿。
完整顶层中938个完全旁路样本与原合成PCM逐位一致；1211个全湿样本中1099个发生变化，覆盖钢琴和吉他。
修改后高云综合、布局布线及上板验收尚待执行。
