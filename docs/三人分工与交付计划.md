## 三、固定技术路线

详细数据和时序看[接口约定](接口约定.md)。从第一天用八键端口，一键阶段其余七路松开，四键阶段后四路松开。

- 主时钟 50MHz，低电平复位，A 统一复位释放。
- 采样率 48,828.125Hz=50MHz/1024，不能称精确 48kHz；频率字按实际值算。
- BCLK 3.125MHz，标准 I2S 一位延迟，左右各 32 位时隙，16 位采样高位有效其余补零，两声道同一混音。
- 帧 n 请求计算，帧 n+1 装载发送，首帧零；核心目标≤128 个主时钟周期，准确值由队长仿真、A 复核。
- 静音发零、时钟不断，正常演奏功放保持启用，不随每次按键开关。
- MCP3208 八路单端输入，3.3V 供电/参考，500kHz SPI 起步，每 1ms 扫描八路并整组交接。
- 压力片与 2kΩ 分压，使按压时读数上升；ADC 附近 100nF 去耦，按官方引脚图接电源和地。
- 每键独立校准；Ton>Toff，连续两轮扫描确认状态；轻度平滑为旧值+(目标−旧值)/4，保留精度避免截断卡住；按住保留可用最小力度。
- 核心松开时冻结松开前力度，ADSR 从当前值 Release，B 的零力度不能截断收尾；重按从当前包络 Attack，更新力度，相位首版连续。
- 默认音 C4/D4/E4/F4/G4/A4/B4/C5。三个普通用户键控制音色、音区（原始→升八度→降八度）、演奏/测试模式，不误用电源或重配置键。

参考：[MAX98357A 手册](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX98357A-MAX98357B.pdf)、[MCP3208 手册](https://ww1.microchip.com/downloads/en/DeviceDoc/21298E.pdf)、[板卡资料](https://wiki.sipeed.com/hardware/en/tang/tang-mega-60k/mega-60k.html)。不能用旧 PT8211 发送格式替代标准 I2S，外接模块引脚由 A/B 对实际版本核对。

ADSR 起步 A=2ms、D=60ms、S≈65%、R=100ms；按实际采样率算，内部精度避免步长为零。两音色采用正弦和 0.75sinθ+0.25sin2θ 单周期表，同一结构，检查音区内谐波与幅度；同音高、相近响度比较，不冒称真实乐器模型。

先仿真再交付；用假 gate、固定力度、不等真实 ADC。队长协调限于接口、核心评审、进度取舍和技术结论。

## 九、验收与测量

详细清单见[交接与验收记录](交接与验收记录.md)。仿真、上板、仪器结果分别记录。

- 一键：静止不响，按下发声，持续压力改响度，松开停止；加入ADSR后正常释放；输入/核心/输出独立证据。
- 四/八键：同按正常，只松第二键其他相位/包络继续；只变一键力度其他控制不变；固定混音比例，极值不回绕；正常无缺帧。
- 两独立维度：保持和弦只变一键压力；保持一键压力再选/放其他键，实物证明分别控制。
- 四路纯正弦谱峰随对应声部开关变化，不能把谐波当四声部。
- 参数与边界：功能键不丢/重复，起音中松开、释放重按、快速重复、长按；30分钟连续测试；复位/断电/搬动恢复；重建后同功能。

### 10ms 总延迟

万用表不能证明10ms。A在10/12联系借仪器，10/23准备，10/24执行：

- 起点为实际分压电压越过约定触发阈值，终点为实际扬声器电气输出出现符合幅度判据的音频。
- 包含扫描、稳定判定、平滑、ADSR、计算、缓冲和DAC/功放；内部valid仅辅助。
- 不同通道、扫描相位、轻重触发重复测，保存最大值和不确定性。
- 正常起音过慢则调输入/包络再测，不只测绕过这些环节的专用模式。
- Class D差分扬声器输出需适当差分测量和音频恢复/滤波；普通示波器地夹不能接任一扬声器输出端。借仪器时向实验室确认接法。
- 没仪器则标“未实测”，不能写≤10ms已通过；记录仪器、接法、幅度判据、重复结果和原始波形。
