# Vibrato版修改范围

新增rtl/audio/audio_vibrato.v、tables/vibrato_sine256.hex，提供共用的混音后分数延时音高颤动。
顶层增加音效实例及参数，让处理后的PCM同时送功放和频谱显示。没有增加外部端口。
解析器增加可选Vibrato命令开关；本工程启用VIBON/VIBOFF/VIBSTAT。
下载控制器保存独立的音效开关并生成回复，支持无曲谱、下载中、教学中控制；不影响CRC和按键评分。
蓝牙控制封装增加开关输出，回复模块和ROM追加23到26号回复。
工程与文件列表加入新音效模块。

原压力模块、钢琴/吉他合成、音区设置、ADSR、混音器、I2S输出、显示RTL、教学控制器、曲谱、CST、SDC和GUI实现配置均保持原字节。
源码保护记录见evidence/source_preservation.json。按对即推进版本的上板通过状态由用户报告，当前修改版需重新编译与上板。
本包没有新FS，不得把历史实现结果作为新增音效的实现结果。
