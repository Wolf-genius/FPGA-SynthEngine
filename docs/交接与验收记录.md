## 阶段验收清单

勾选时附日期、版本、负责人、输入/预期/实际和证据。仿真不能自动替代真实硬件项。

### 接口与独立模块

- [ ] 三人确认八键端口、通道顺序、复位、同沿更新和事件接收。
- [ ] DDS频率、复位、回绕、无使能保持、变调仿真。
- [ ] 波表路径可重建，地址、符号、读取延迟、valid对齐。
- [ ] I2S接收恢复零/正负/极值/连续帧/左右数据，一位延迟正确。
- [ ] SPI指定12位返回值、八路通道与整组控制交接正确。
- [ ] 已知真实电压与ADC读数一致，1ms扫描验证。
- [ ] 连续/同时按钮事件、controls_valid与sample_ce同沿行为验证。

### 一键、四键、八键

- [ ] 真实一键静止不响、按下发声、持续压力变响度、松开停止。
- [ ] 合成核心、标准I2S、MAX98357A真实闭环，归档演示。
- [ ] ADSR释放不被零力度截断，起音中松开/释放重按正常。
- [ ] 四键四声部同按/分别松开/力度独立。
- [ ] 八键八声部同按，只松第二键其他状态继续。
- [ ] 和弦保持只改一键力度，其他控制不变；演示选音/力度两维分别控制。
- [ ] 八路极值/抵消不回绕，固定除以八、最终限幅。
- [ ] 请求/结果/缓冲/装载对应，首帧零，正常缺帧零。
- [ ] 核心实际L=待记录，满足≤128周期目标及发送期限。

### 参数、测量与稳定性

- [ ] 两音色同音高/相近响度，实时八度循环。
- [ ] 三功能键长按一次，不丢事件、不重复。
- [ ] 长按、快速重复、起音中松开、释放中重按回归。
- [ ] 四路纯正弦各谱峰随对应声部开关变化。
- [ ] 模拟输出总延迟实测，最大值/不确定性及≤10ms结论。
- [ ] 30分钟连续测试、复位、断电上电和搬动恢复。
- [ ] 综合/布局布线时序和资源复核。

### 重建与提交

- [ ] 另一电脑重建，工具、源码、表、约束、配置齐全，相对路径可复现。
- [ ] 报告参数与代码一致，实测与推算分开。
- [ ] 视频覆盖验收项且与源码/码流同版。
- [ ] 源码提交号、码流、接线、校准、报告、视频、证据对应。
- [ ] 平台格式、上传、下载复查、凭证和备份完成。
