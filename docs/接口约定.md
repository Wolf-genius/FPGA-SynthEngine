# 八键压力电子琴接口约定 v1

更新：2026-10-10。替代四键gate与单pressure_gain接口。规定开发目标，不表示RTL已实现或上板通过。内部模块接口不同于CST物理引脚；外部GPIO由A/B核对实际板卡、原理图和电压。

## 1. 端口与通道

| 信号 | 提供者→接收者 | 约定 |
|---|---|---|
| clk/rst_n | A→全部 | 50MHz同一域，低有效复位，释放统一处理；旧sys_clk在top映射 |
| sample_ce | A→核心 | 单主时钟周期，每1024周期请求一组声音 |
| gate[7:0] | B→核心 | 1按住、0松开，允许多位为1 |
| key_gain[127:0] | B→核心 | 八组16位无符号，0零增益、65535≈单位增益 |
| controls_valid | B→核心 | 单周期，完整gate/key_gain控制帧有效 |
| button_events[2:0] | B→核心 | 已同步消抖的单周期事件，长按不重复 |
| mixed_sample[15:0] | 核心→A | signed 16位补码，−32768…32767 |
| mixed_valid | 核心→A | 单周期，结果与一次请求对应 |

CHi→gate[i]→key_gain[16*i +: 16]→voice i；CH0增益在[15:0]，CH7在[127:112]。i=0…7音符依次C4/D4/E4/F4/G4/A4/B4/C5。

一键只启用CH0，四键CH0…3，其余gate/gain为零；从第一天端口不变。DDS phase_step=round(f×2^32/48,828.125)，不能用精确48kHz参数。

## 2. 控制更新与事件

B每1ms扫描八个单端通道，内部缓存中间结果；完整处理后一起更新gate/gain并给valid。有效沿可接收，保持到下一完整更新，不交半组新旧数据。

核心每主时钟接收完整帧，sample_ce时锁定此前已收到的控制。controls_valid与sample_ce同沿：当前用旧帧，下个采样用新帧，testbench按此检查非阻塞赋值行为。

| 事件位 | 动作 | 复位 |
|---|---|---|
| 0 | 正弦/含二次谐波音色切换 | 正弦 |
| 1 | 原始→升八度→降八度→原始 | 原始 |
| 2 | 演奏/频谱测试模式切换 | 演奏 |

核心每主时钟接收并保存事件，采样边界应用，不只在sample_ce检查。事件同沿用旧设置、下采样用新设置；不同位同时有效全部处理，相邻周期事件分别累计，不能用单pending位合并多次动作。

测试模式提供四路固定不同频率/固定增益纯正弦和逐路开关，由队长与A的测试top提供测试控制；不改正式八键打包。回演奏使用最新完整真实控制帧。

复位：gate/gain零、包络Idle、输出零、默认正弦/原始音区/演奏模式；测试声音通过明确模式启用，不用隐含满增益掩盖无输入。

## 3. 力度与释放

B每键实测Ton/Toff，Ton>Toff，连续两轮扫描确认。目标限幅，旧值+(目标−旧值)/4轻度平滑，内部保留精度避免末值卡住；按住保留可用最小力度。实际阈值、映射端点、最小力度填写校准记录，不编造通用数字。

B松开增益可归零；核心保存每声部上次按住力度。gate下降时冻结此前值进入Release，不被松开帧零增益覆盖。释放途中输入零不截断音尾；重按从当前包络Attack，更新力度，相位连续。

ADSR起步A=2ms、D=60ms、S≈65%、R=100ms，按实际采样率、当前包络算，限幅，足够精度避免步长为零。每声部波形×包络×力度明确符号/乘积位宽/缩放；八路16位先符号扩展，至少19位求和、固定除以八、最终16位限幅，不随键数改变比例。

## 4. 音频请求、计算和装载

| 参数 | 目标 |
|---|---|
| 主时钟 | 50MHz |
| 采样间隔/实际采样率 | 1024周期 / 48,828.125Hz |
| BCLK | 3.125MHz=50MHz/16 |
| I2S | 标准一位延迟，左右各32位时隙；16位高位采样，其余零，两声道相同 |
| 核心延迟 | 目标≤128主时钟周期，精确L待实现仿真后填写 |

帧n边界装载此前结果并发新请求；帧n内核心计算、valid返回、A缓冲；帧n+1装载帧n请求结果。第一帧零，不计缺帧。每次请求恰好一个有序结果；所有声部属同一采样，数据和valid对齐。

A在mixed_valid对应沿接收，不能在请求同沿认为拿到新数据。结果必须在下一装载沿之前已缓冲，边界同沿不依赖特殊旁路；未到则本帧零并记缺帧，不重放旧值掩盖问题。正常缺帧为零。精确L由队长记录、A复核期限。

静音保持时钟/发零，正常功放持续启用。不能照搬PT8211的LSB-justified格式。

## 5. 独立验证与交接

队长用假gate/增益验证核心；A固定样本+接收仿真验证标准I2S/缓冲/缺帧；B假ADC验证帧/位序/通道，再已知电压和真实压力校准。联合依次一/四/八键，覆盖松一路、单键力度、同沿更新、连续事件、复位。

交接附端口/符号/位宽、更新条件、复位值、延迟、版本、测试方法、问题。变更先写影响三人确认；精确L、GPIO、校准数值未验证前保留待测。
